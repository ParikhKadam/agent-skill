# Layer gates

## In plain words

A layer is **passed** only when its gate condition is met and you can point to the evidence (a doc id, a measurement, a person's agreement). Use `skipped` for layers the size does not need, and say why in Notes. Status is `not-started`, `in-progress`, `passed` or `skipped`.
